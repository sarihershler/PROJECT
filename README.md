# פורטל קליטה לעובדים חדשים

עמוד HTML יחיד (`index.html`) – ללא תלויות או שלב בנייה. פותחים בדפדפן ומוכן.

## התאמה אישית
1. בתחתית `index.html` ערכו את האובייקט `CONFIG` (שם החברה, מחלקה, שם העובד/ת, פרטי מנטור/ית, מנהל/ת ו-HR).
2. החליפו את הקישורים הפנימיים המסומנים ב-`TODO` (חוברת עובד, מדריך אבטחת מידע, סרטון תרבות).
3. להוספת כרטיסייה – העתיקו `<li class="card" data-id="...">` קיים ותנו לו `data-id` ייחודי.
